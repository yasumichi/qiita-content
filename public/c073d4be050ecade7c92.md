## きっかけ

今更、CompTIA Network+ を受験しろと上が言うので…

せっかくなので音声学習をしようと思い、教材のテキストを VOICEVOX で読み上げさせてみることにしました。

しかし、実際に読み上げさせてみると「CIDR（サイダー）」がうまく読めなかったり、「光信号」を「ミツノブゴウ」と読んだりしたため、自分でネットワーク用語のユーザー辞書を作成して公開してみることにしました。

https://voicevox.hiroshiba.jp/

## GitHub で公開してみました

https://github.com/yasumichi/VOICEVOX-network-words

リポジトリごと clone する場合は、以下のコマンドを使用してください。

```
git clone https://github.com/yasumichi/VOICEVOX-network-words.git
```

ユーザー辞書のみダウンロードしたい場合は、以下のコマンドなどを使用してください。

```
curl -o network-words.json https://raw.githubusercontent.com/yasumichi/VOICEVOX-network-words/refs/heads/main/network-words.json
```

または

```
wcurl https://raw.githubusercontent.com/yasumichi/VOICEVOX-network-words/refs/heads/main/network-words.json
```

## インポート方法

### VOICEVOX の Web インターフェースを利用する場合

1. `http://127.0.0.1:50021/setting` にアクセス
2. `ユーザー辞書のインポート`節にある `インポート` ボタンをクリック
3. `参照` ボタンで `network-words.json` を選択
4. `インポート` ボタンをクリック

### curl インターフェースを利用する場合

環境に応じて、以下のコマンドを利用してください。それぞれに対応したスクリプトファイルも同梱しています。

#### Linux の場合

```
curl -X POST "http://127.0.0.1:50021/import_user_dict?override=true" \
  -H "Content-Type: application/json" \
  -d @network-words.json
```

#### Windows (コマンドプロンプト) の場合

```
curl -X POST "http://localhost:50021/import_user_dict?override=true" -H "Content-Type: application/json" -d "@network-words.json"
```

#### Windows (Powershell) の場合

```
curl.exe -X POST "http://localhost:50021/import_user_dict?override=true" -H "Content-Type: application/json" -d "@network-words.json"
```

または

```
Invoke-RestMethod -Uri "http://localhost:50021/import_user_dict?override=true" -Method Post -InFile "network-words.json" -ContentType "application/json"
```
